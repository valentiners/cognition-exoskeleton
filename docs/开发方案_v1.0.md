## 1. 项目定位

- **是什么**：一款大模型的"认知灵魂外挂"（cognition-exoskeleton，包名 voiceofsoul）。完全独立于基础模型，**不修改任何模型权重**，通过外挂「认知模块 + 记忆模块」让任何已训练模型获得持续自我学习能力。
- **当前状态**：primitive version（最小可运行闭环），Apache-2.0 开源，仓库 `cognition-exoskeleton`，作者署名 Ricky Li（个人，不出现公司名）。
- **运行形态**（v1 目标）：
  1. 独立模块，基于本地 Ollama 服务 + 浏览器直接使用（✅ 已实现）；
  2. 可作为 OpenClaw 的技能插件配合调用（⬜ 待开发，插件规范待定）；
  3. 保留对接视频模型获取外界现实世界信息参数的接口（⬜ 预留）。

## 2. 不可动摇的核心原则

任何代码变更不得违反以下原则；如有冲突，停下来问主人而不是擅自取舍：

1. **原模型只被调用，权重与源文件永不被修改**；
2. **单主人原则**：一个服务实例只服务一个主人，主人身份即最高权限与唯一可信输入源；不预留多主人/多角色权限层（多主人公是架构级变更，明确不允许）；
3. **一切状态变更只追加、不覆盖**，保留完整演化轨迹；
4. **embedding 与基础模型解耦**：向量由独立外部编码器生成，更换基础模型零迁移成本；
5. **防重复记忆**：基础模型压缩知识已覆盖的，绝不重复入库（常识直通）；
6. **交互拟人化**：对主人的表达要像鲜活的对话者，机械标注只留在 debug 字段；**不用按钮做选择**，判断通过对话本身完成。

## 3. 当前系统架构（已实现）

```
浏览器 UI (web/index.html, 原生JS)
    │ HTTP (127.0.0.1:8600)
    ▼
server.py (stdlib-only 测试服务, ThreadingHTTPServer)
    │
    ├── voiceofsoul/cognition.py   认知模块：识别流程 + 三道闸口 + 学习/纠错
    ├── voiceofsoul/memory.py      永久记忆：主条目 entries + 补丁 patches
    ├── voiceofsoul/temp_memory.py 临时记忆：七天法则（见 §5.2）
    └── voiceofsoul/adapters/ollama.py  适配层：OllamaBaseModel + OllamaEmbedder
                    │
                    ▼
            本地 Ollama (localhost:11434)
```

- 内核（`voiceofsoul/`）**零第三方依赖**，只用标准库；适配层通过 HTTP 调用 Ollama，模型可热切换。
- `server.py` 只是"最小验证载体"，不是最终形态；正式开发时应把内核打包为可独立导入的库 + 多种前端载体。

## 4. 识别流程（认知模块 perceive）

定型顺序（**基础模型先认知，外挂只做它做不了的**）：

1. **永久记忆高阈值命中**（≥ mem_th=0.78）→ RECOGNIZED；
2. **基础模型先判断**（`infer_confidence` + `infer`）：
   - 认识的类别下恰好一个专名 → `judge_same` 同一性裁决：是→认出；否→落未知/命名；拿不准→GUESS 问主人；
   - 类别下多个专名候选 → GUESS；
   - 与任何专名无关 → **DIRECT 常识直通，不打扰主人**；
3. 基础模型不确定 → 向量近邻（≥0.5）+ `judge_same` 兜底；
4. 全不成立 → UNKNOWN，进入命名教学。

**定型的教训**：旧版"灰色地带事事弹窗问主人"被否决——每次提问都是打扰，应先让基础模型自己判断，它真拿不准才升级给主人。

### 4.1 感知通道

- 图像（通道 A）：先经 `perceive_image` 转统一文字描述，**先声明"我看到一张图片——"再描述内容**，之后与文本完全同路；
- 文本（通道 B）：直接进识别流程；
- 纯问题（"是什么/为什么/吗/?" 等，无图）→ 常识问答直通 `answer_question`，不进记忆流程。

## 5. 记忆机制（本轮最大改动）

### 5.1 永久记忆（memory.json，git 忽略）

- 主条目 entries（专名/私人知识）+ 补丁 patches（公共知识粒度补充，含审计字段）；
- 入库必经**三道闸口**：闸口 1 GUESS 确认回环（"是普通的 X 还是有特别之处"）；闸口 2 专名/通名自检（问基础模型"公共知识还是私人事物"，**不问"认不认识这个词"**——后者会把"小黄""Lucy"这类常见人名误判成公共知识，已踩坑并修正）；闸口 3 建库前向量查重（≥mem_th → MERGE 只追加）。

### 5.2 临时记忆 + 七天法则（temp_memory.json，git 忽略）

主人定型的规则（2026-10-19），**替代了早期的"按钮仲裁"**：

1. 所有新事物的特征**一律先暂存**到临时记忆（独立文件）；
2. 主人对话里说"记住它" → 立即晋升永久记忆（走三道闸口）；
3. 主人没说 → 留在临时记忆，**滚动保留 7 个自然日**，超期自动遗忘；
4. **同一事物 7 天内在不同日期出现 ≥3 次 → 自动晋升**永久记忆，并在对话中自然告知主人（"它这几天老是出现，我就把它正式记住了"）；
5. 晋升时缺名字 → 对话式追问（"那我该怎么称呼它？"），主人自由文本即回答。

实现要点：窗口滑动（cutoff = 今天 - 6 天，最早一次出现会滑出窗口）；`touch()` 在每天首次出现时记一个日期；阈值 TempMemory.MATCH_TH=0.62（低于永久记忆的 0.78，宽松命中）。

### 5.3 对话式意图理解（无按钮原则）

- 主人在话题上下文中的每句话，由 `classify_followup(context, utterance)` 一次 LLM 调用分类：`feature`（补充信息，"属性: 内容"）/ `remember` / `forget` / `none`；关键词正则仅作 LLM 失败时的兜底；
- **一切未决流程的自由文本都是回答**（arbitrate/guess/gate1/naming 等），带模糊理解（"不是/不对/没"→否，"是/对/嗯"→是，"算了/取消"→取消）；按钮仅保留为可选便利，不是唯一通道；
- 话题有 30 分钟冷却期，超时自动作废（鲜活生命体不无限盯着旧话题）；
- 对主人的所有回复必须拟人、口语、第一人称；机械信息（action=xxx、置信度）只放 debug 字段。

## 6. 两天迭代修改点清单（含踩坑记录）

| 时间 | 修改点 | 关键教训 |

| 10-19 | **临时/永久双层记忆 + 七天三次法则；废除按钮，自由文本即回答** | 见 §5.2/§5.3 |

### 环境级经验（代码 agent 必读）

- embedding 选型已标定：**embeddinggemma-2 + mem_th=0.78**（mxbai-embed-large 对中文正负例完全分离失败，已弃用，勿回退）；
- 本机 `python`/`python3` 指向 Kimi 内部运行时（3.12）；Git Bash 里 `curl -d` 带中文会被转成 GBK 导致服务端 JSON 解析失败——**中文测试请求必须 `--data-binary @文件` 或 python urllib**；
- Ollama 冷启动要 1~3 分钟，HTTP 客户端 timeout ≥600s；后台启动服务用 `(python server.py > server.log 2>&1 &)`。

## 7. 接口与配置

### 7.1 启动参数（server.py）

| 参数 | 默认值 | 说明 |
|---|---|---|
| `--port` | 8600 | 测试服务端口（start.bat 的排他判断硬编码此端口，改端口需同步） |
| `--base-model` | gemma4:latest | 基础模型（vision+text 必备） |
| `--embedding-model` | embeddinggemma-2:latest | 独立编码器 |
| `--memory` / `--temp-memory` | memory.json / temp_memory.json | 运行数据，均 git 忽略 |
| `--mem-th` / `--base-th` | 0.78 / 0.51 | 已按 embeddinggemma-2 标定，勿随意改 |

### 7.2 HTTP API

- `POST /api/chat` `{text, image(dataURL|base64)}` → `{say, actions, debug}`；`GET /api/models`；`POST /api/switch`；`GET /api/stats`（含 temp 记录）；
- 适配层探测点（对任何新基础模型都要实现这套契约）：`infer` / `infer_confidence` / `describe` / `is_public_knowledge` / `judge_same` / `classify_followup` / `answer_question` / `perceive_image`。

### 7.3 测试

- 单元：`_test_temp_memory.py`（七天法则全分支，mock 日期，不依赖 Ollama）——改动记忆逻辑后必须跑通；
- 端到端：`_test_lucy.py`（本地脚本，git 忽略）按"图→特征→记住→认出"全链路验证；改识别/记忆主流程后必须全绿再交付。
